# Material Design 3 desktop shell

The SandMan shell uses shared Material 3 surface, primary, outline, typography, focus, tab, menu, field, table, toolbar, status, and scrollbar roles.

## Configuration

Light/dark appearance, font family, font scale, language mode, funny levels, and dialog emoji presentation are persisted in the profile settings.

## Verification

Build the Qt desktop target, open Settings and Options at 100% and 200% scale, then check keyboard focus and the bundled offline article search.

Suggested articles: [Contributor capability mode](contributor-build.md).
